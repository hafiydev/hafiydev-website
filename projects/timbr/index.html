Timbr

Overview

Released

Timbr chops a whole tree in one break instead of one log at a time. Cut behaviour is bounded by configuration: a maximum number of logs, and what counts as a tree. Every block is checked against region protection before it is removed, so it works alongside protection plugins rather than around them.

Targets Minecraft 1.20.x; the paper.version property selects the exact API build.

Features

Confirmed
  • Fells an entire tree from a single broken log
  • Configurable maximum logs and cut behaviour
  • Checks region protection before removing any block
  • Built against the Paper API with Java 21

Installation

  1. Build with mvn -Dpaper.version=1.20.2-R0.1-SNAPSHOT clean package.
  2. Drop the resulting jar from target/ into your server plugins/ folder.
  3. Edit config.yml for the maximum logs and cut behaviour, then restart.
  4. Set paper.version to a different 1.20.x API build if you need a newer patch.
